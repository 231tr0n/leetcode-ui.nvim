*LeetCodeNet* HTTP layer on top of curl

------------------------------------------------------------------------------
                                                         *LeetCodeNet.request()*
                         `LeetCodeNet.request`({opts})
an HTTP request.


- `url` (string, required)
- `method` (`'GET'|'POST'|'PUT'|'DELETE'`, default `'GET'`)
- `headers` (array of raw `'Name: value'` strings)
- `body` (string|nil raw request body)
- `timeout` (number seconds, default 30)
- `retries` (number of transient-failure retries, default 3)

`{status, headers, body}` and an error string on transport failure.
a coroutine, yields until the request completes.

Parameters ~
{opts} `(table)` Request options.
Return ~
`(table|nil)` Response
Return ~
`(string|nil)` Error

------------------------------------------------------------------------------

      `LeetCodeNet.request_json`({url}, {body}, {headers}, {cookie_file})

{headers} `(table|nil)` Extra raw header strings.
